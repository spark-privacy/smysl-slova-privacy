# Политика конфиденциальности  
**Приложение «Смысл слова и контекста»**  

**Дата обновления:** 15 февраля 2026

## 1. Общие положения
Настоящая Политика конфиденциальности описывает, какие данные обрабатываются в мобильном приложении «Смысл слова и контекста» (далее — Приложение), и как они используются.  
Приложение ориентировано на приватность и работу с языком, нормой речи и контекстом.

## 2. Какие данные обрабатываются
Приложение **не запрашивает и не обрабатывает персональные данные**, такие как:
- имя, адрес электронной почты, номер телефона;
- геолокация;
- паспортные или платёжные данные.

Приложение хранит **только локальные технические данные на устройстве пользователя**, необходимые для работы функций:
- настройки (например, напоминания и тактильный отклик);
- история раздела «Сегодня»;
- избранное;
- архив словаря и локальные отметки/прогресс.

## 3. Как используются данные
Локальные данные используются исключительно для работы функций Приложения:
- сохранение предпочтений и прогресса;
- восстановление истории и избранного;
- удобство использования.

Приложение не осуществляет профилирование пользователей, не показывает рекламу и **не передаёт локальные данные разработчику**.

## 4. Хранение и удаление данных
Все данные сохраняются локально на устройстве пользователя.  
Пользователь может удалить локальные данные через: **Настройки → «Очистить локальные данные»**.

## 5. Передача данных третьим лицам
Приложение **не передаёт** данные третьим лицам и **не использует** сторонние рекламные или аналитические SDK (трекеры/рекламные сети).

## 6. Уведомления
Приложение может использовать **локальные уведомления** для напоминаний о разделе «Сегодня».  
Уведомления формируются на устройстве пользователя и не требуют передачи данных на сервер.

## 7. Изменения политики
Политика может обновляться по мере развития функциональности.  
Актуальная версия доступна по официальной ссылке (GitHub Pages) и/или внутри Приложения.
