# Политика конфиденциальности

**Приложение «Смысл слова и контекста»**  
**Идентификатор Android:** `online.sparkheritage.smyslslova`  
**Дата обновления:** 28 августа 2026 года

## 1. Общие положения

Настоящая политика описывает обработку данных в мобильном приложении «Смысл слова и контекста» (далее — Приложение). Приложение предназначено для пользователей в возрасте 13 лет и старше.

Контакт по вопросам конфиденциальности: **02042022@bk.ru**.

## 2. Локальные данные

Для работы функций Приложение хранит на устройстве пользователя:

- настройки уведомлений, рекламы и тактильного отклика;
- историю раздела «Сегодня»;
- избранное;
- архив словаря, результаты и прогресс.

Эти данные не передаются разработчику и могут быть удалены через настройки Приложения либо при его удалении.

## 3. Обратная связь

При отправке обращения пользователь добровольно передаёт:

- текст сообщения и выбранную тему;
- имя и адрес электронной почты, если пользователь их указал;
- технические сведения: модель устройства, версия операционной системы, версия и номер сборки Приложения, язык интерфейса.

Эти сведения передаются по защищённому HTTPS-соединению на сервер обратной связи и используются только для ответа на обращение, диагностики ошибок и улучшения Приложения. Они хранятся не дольше, чем это необходимо для обработки обращения и соблюдения применимых требований. Запрос на удаление можно направить на **02042022@bk.ru**.

## 4. Реклама

Приложение использует Yandex Mobile Ads SDK для показа вознаграждаемой рекламы. Рекламный SDK может обрабатывать и передавать Yandex и его рекламным партнёрам:

- рекламный идентификатор устройства;
- технические сведения об устройстве и приложении;
- IP-адрес и приблизительные сетевые сведения;
- сведения о показах, взаимодействиях с рекламой и предотвращении мошенничества.

Цели обработки: показ и измерение рекламы, ограничение частоты показов, обеспечение безопасности и предотвращение рекламного мошенничества.

При первом запуске пользователь выбирает персонализированную или неперсонализированную рекламу. Выбор можно изменить в разделе «Настройки → Реклама». Основные функции Приложения доступны при любом выборе. Приложение не передаёт рекламному SDK точную геолокацию.

Подробнее: [Политика конфиденциальности Yandex](https://yandex.com/legal/confidential/) и [документация Yandex Mobile Ads](https://ads.yandex.com/helpcenter/en/dev/).

## 5. Уведомления

По выбору пользователя Приложение создаёт локальное ежедневное напоминание. Разрешение запрашивается средствами операционной системы. Для уведомлений не используется удалённая рассылка и не требуется передача пользовательских данных на сервер.

## 6. Данные, которые Приложение не запрашивает

Приложение не запрашивает точную геолокацию, контакты, фотографии, микрофон, платёжные данные, паспортные данные и не создаёт пользовательские аккаунты.

## 7. Возрастная аудитория

Приложение не предназначено для детей младше 13 лет. Если разработчику станет известно о получении персональных данных ребёнка младше 13 лет, такие данные будут удалены после обращения по адресу **02042022@bk.ru**.

## 8. Защита и передача данных

Данные формы обратной связи и рекламного SDK передаются по защищённым соединениям. Данные могут обрабатываться поставщиками инфраструктуры и рекламными партнёрами только для описанных выше целей и в соответствии с их условиями и применимым законодательством.

## 9. Права пользователя

Пользователь может:

- отключить персонализацию рекламы в настройках Приложения;
- отключить уведомления;
- удалить локальные данные;
- запросить сведения об обращениях, их исправление или удаление по адресу **02042022@bk.ru**.

## 10. Изменения политики

Политика может обновляться при изменении функций, используемых сервисов или требований законодательства. Актуальная версия публикуется по адресу:

<https://spark-privacy.github.io/smysl-slova-privacy/>
